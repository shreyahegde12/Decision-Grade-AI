Connect editor

The browser dashboard works independently. Add the extension for checks inside your editor.

  1. Keep npm start running in your terminal.
  2. In your VS Code-compatible editor, open Extensions → Install from VSIX… and choose dist/trustgate-0.2.0.vsix.
  3. Run TrustGate: Set API Token from the command palette and enter your local developer token.
  4. Open a Git repository with an origin remote, then click the TrustGate shield.
  5. Use Check saved changes for previews or Review commit range before pushing.

The Git pre-push hook is a separate installation. The dashboard does not access your local repository directly.
